# Hackles

iPhone app for wristband-based gamefowl registry — yards, biodata, search, and Premium.

## Stack

- SwiftUI + SwiftData
- iOS (iPhone only)
- Bundle ID: `tinio.hackles`

## Open in Xcode

```bash
open Hackles.xcodeproj
```
